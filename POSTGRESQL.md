# Executar com PostgreSQL

O projeto usa PostgreSQL, com banco `estanteweb` em `localhost:5433` e usuário/senha locais `estanteweb`. A URL, o usuário e a senha podem ser substituídos pelas variáveis `DATABASE_URL`, `DATABASE_USER` e `DATABASE_PASSWORD`.

As migrações Flyway criam as tabelas e inserem o acervo inicial em um banco novo. Os ids usam `GENERATED BY DEFAULT AS IDENTITY`.

Neste ambiente foi iniciada uma instância separada do PostgreSQL 16. Os dados ficam em `/tmp/estanteweb-postgres/data`, uma pasta temporária que pode ser apagada pelo sistema. Para uso permanente, configure um banco com armazenamento persistente.

Para reiniciar essa instância enquanto os dados existirem:

```sh
/usr/lib/postgresql/16/bin/pg_ctl -D /tmp/estanteweb-postgres/data -l /tmp/estanteweb-postgres/server.log -o '-p 5433 -h 127.0.0.1 -k /tmp/estanteweb-postgres' start
```

Para executar a aplicação e os testes:

```sh
./mvnw spring-boot:run
./mvnw test
```
